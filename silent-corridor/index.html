SCENARIO
Situation & Scope

The BfV (German Federal Intelligence Service) issued a confidential advisory warning that state-sponsored threat actor GREY VEIL had been conducting targeted intrusions against European aerospace and defence contractors since late 2025. Their objectives: intellectual property theft and persistent access to engineering networks.

Haldric Aerospace, a Tier 2 defence contractor specialising in avionics navigation systems for European military programmes, commissioned a proactive threat hunt. No alerts. No IoCs. Just an advisory and 14 days of telemetry from the engineering segment.

GREY VEIL tradecraft is characterised by zero custom tooling — they operate entirely with living-off-the-land techniques. No malware. No signatures. Traditional detection fails completely against this actor.

DETECTION
Key KQL Queries

All investigation conducted in Microsoft Sentinel against the unified SilentCorridorX_CL custom log table. Critical note: TimeGenerated reflects ingestion time — always filter on EventTime for actual event timestamps.

// Base filter — use at the top of every query let HuntData = SilentCorridorX_CL | where isnotempty(EventTime) | where TimeGenerated > datetime(2026-04-07T14:00:00Z); // Account profiling — find the outlier HuntData | where MdeTable == "FortiGateVPN" | summarize TotalEvents = count(), UniqueIPs = dcount(RemoteIP), FirstSeen = min(EventTime), LastSeen = max(EventTime) by AccountName | sort by UniqueIPs desc
// Credential harvesting commands on beachhead HuntData | where MdeTable == "DeviceProcessEvents" | where DeviceName == "WS-ENG04" | where ProcessCommandLine has_any ("lsass", "comsvcs", "MiniDump", "reg save", "cmdkey", "ntdsutil", "portproxy") | project EventTime, FileName, ProcessCommandLine | sort by EventTime asc
// Detect WMI-based lateral movement from beachhead HuntData | where MdeTable == "DeviceProcessEvents" | where FileName == "WMIC.exe" | where ProcessCommandLine has "process call create" | project EventTime, DeviceName, ProcessCommandLine | sort by EventTime asc

CONFIRMED: GREY VEIL INTRUSION

State-sponsored threat actor GREY VEIL successfully compromised Haldric Aerospace with a 13-day dwell time before detection. All activity was conducted using native Windows tools — no malware, no custom tooling, zero endpoint alerts during the entire intrusion lifecycle.

Critical classified material — A400M navigation system engineering data — was successfully exfiltrated to attacker-controlled infrastructure. The full Active Directory credential database (ntds.dit) was also extracted, meaning all domain accounts must be treated as compromised. Port proxy persistence mechanisms survive both reboots and credential resets.

The only telemetry that survived the attacker's log-clearing operations was Sysmon — collected to a separate event channel not touched by wevtutil. This was the sole basis for the entire investigation.
